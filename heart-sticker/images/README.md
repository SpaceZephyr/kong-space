# Logo 文件说明

请在此目录下放置以下文件：

## 必需文件

1. **logo.png** - 网站左上角显示的 Logo
   - 推荐尺寸：32x32 像素或更高分辨率的正方形
   - 格式：PNG（支持透明背景）
   - 用途：显示在页面左上角，品牌标识

2. **favicon.ico** - 网站页签图标
   - 推荐尺寸：16x16, 32x32, 48x48 像素（多尺寸ICO文件）
   - 格式：ICO
   - 用途：显示在浏览器页签、书签等位置

## 可选文件

- **apple-touch-icon.png** - iOS 设备主屏幕图标
  - 推荐尺寸：180x180 像素
  - 格式：PNG

## 注意事项

- 确保文件名与代码中引用的名称完全一致
- Logo 设计应简洁明了，在小尺寸下也能清晰显示
- 建议使用品牌色彩，与网站整体风格保持一致
